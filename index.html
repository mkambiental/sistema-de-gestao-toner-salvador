Parâmetros de Previsão

A previsão agora usa o histórico real de trocas de cada impressora e toner. Os parâmetros abaixo controlam somente a confiança, os alertas e as novas tentativas.

Quantidade de ciclos completos antes de estimar a próxima troca.

Quantos dias antes da previsão o sistema deve sinalizar atenção.

Quantidade de negativas consecutivas para elevar o nível de risco.

Prazo usado para orientar uma nova solicitação após uma negativa.

A média de duração e a próxima troca são calculadas automaticamente a partir das trocas reais registradas para cada impressora e cor. Não é mais necessário informar um consumo médio fixo.
